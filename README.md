# Bibliotecnm - Aplicación Móvil

Aplicación móvil para la gestión de biblioteca desarrollada en Android utilizando Jetpack Compose, Room Database y Retrofit.

## Tecnologías utilizadas
- **Lenguaje:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Base de datos local:** Room
- **Consumo de API:** Retrofit & Gson Converter
- **Navegación:** Jetpack Navigation Compose
